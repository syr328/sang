Web 前端长度单位

桑英锐 · CSS 长度单位一览

px 绝对单位

像素单位，最常用的绝对长度。1px 对应屏幕上的一个物理像素点（实际渲染受 DPR 影响）。

150 × 60 px

width: 150px; height: 60px;

em 相对单位

相对于父元素的 font-size。若父元素 font-size: 20px，则 1em = 20px。

8em × 2.5em

父级 font-size: 20px → 1em = 20px

rem 相对单位

相对于根元素 (html) 的 font-size。默认 html font-size: 16px，因此 1rem = 16px。适合响应式布局。

10rem × 3rem

根元素 font-size: 16px → 1rem = 16px

% 相对单位

百分比，相对于父元素对应属性的值。宽高百分比依赖父级是否有明确尺寸。

50%

父容器宽 260px → 50% = 130px

vw / vh 视口单位

相对于视口宽度/高度的 1%。vw = viewport width，vh = viewport height。常用于全屏布局。

12vw × 8vh

视口 1920×1080 → 12vw=230px, 8vh=86px

vmin / vmax 视口单位

vmin = vw 与 vh 中较小值的 1%；vmax = 较大值的 1%。保证元素在各种屏幕方向下都有合理尺寸。

15vmin

正方形：宽高 = 15vmin（取视口短边）

ch 相对单位

相对于数字 "0" 字符的宽度。常用于限制文本宽度（如每行 60-80 ch 适合阅读）。

20ch

宽度 = 20 个 "0" 字符的宽度

cm / mm / in 绝对单位

物理长度单位。1in = 2.54cm = 96px，主要用于打印样式表 (print media)，屏幕显示很少使用。

2cm × 1cm

1in = 2.54cm = 96px（屏幕与打印效果不同）
