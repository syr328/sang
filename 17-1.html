JavaScript Object Notation —— 前后端"寄快递"的通用包装格式

JSON 的六种值

字符串 String "name": "桑英锐"

必须用双引号包裹，单引号是语法错误。

数字 Number "age": 20

整数和小数都可以，不用加引号。

布尔 Boolean "vip": true

只有 true 和 false 两个值，小写。

空值 Null "remark": null

表示"这里什么都没有"，也是小写。

数组 Array "skills": ["HTML", "CSS", "JS"]

方括号包裹，逗号分隔，可嵌套任意值。

对象 Object "address": { "city": "大连" }

大括号包裹键值对，键必须加双引号。

三个最常见的 JSON 语法错误

❌ 键和字符串用了单引号 { 'name': '桑英锐' }
✔ 正确：{ "name": "桑英锐" } —— 必须全部用双引号
❌ 最后一个键值对后面多了逗号 { "name": "桑英锐", "age": 20, }
✔ 正确：最后一项后面不能有逗号
❌ 键名没加引号（JS 对象可以，JSON 不行） { name: "桑英锐" }
✔ 正确：JSON 的键必须用双引号包裹
