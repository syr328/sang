JavaScript 基本数据类型

六种数据类型：String / Number / Boolean / Undefined / Null / Object，使用 typeof 运算符检测

六种数据类型一览（点击"运行"查看检测结果）

字符串型

String
var syr_str = "桑英锐";
typeof syr_str;
typeof 结果 → "string"

由零个或多个字符组成的文本，使用单引号或双引号包裹。

数值型

Number
var syr_num = 2026;
typeof syr_num;
typeof 结果 → "number"

整数与浮点数统称为数值型，如 100、3.14，特殊值 NaN 也属于数值型。

布尔型

Boolean
var syr_bool = true;
typeof syr_bool;
typeof 结果 → "boolean"

只有 true（真）和 false（假）两个值，常用于条件判断。

未定义型

Undefined
var syr_undef;
typeof syr_undef;
typeof 结果 → "undefined"

变量声明后未赋值，其值和类型都是 undefined。

空型

Null
var syr_null = null;
typeof syr_null;
typeof 结果 → "object"（历史遗留 bug）

表示"空值"，可用于清空变量。注意：typeof null 返回 "object"。

对象型

Object
var syr_obj = { name: "桑英锐" };
typeof syr_obj;
typeof 结果 → "object"

引用（复合）类型，由键值对组成，数组、函数也属于广义的对象。
