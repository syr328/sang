JavaScript 两种定时器

setTimeout 定时"响一次闹钟"，setInterval 定时"每隔一段时间重复响"

定时器一：setTimeout 延时执行（只执行一次）

var timerId = setTimeout(函数, 毫秒数);   clearTimeout(timerId); // 取消
延时 秒后响铃
⏰ 未设定

形象理解：setTimeout 就像给手机定了一个"一次性闹钟"，到点只响一次； 在响之前可以用 clearTimeout（凭定时器返回的编号 id）把它取消掉。

定时器二：setInterval 间隔执行（重复执行）

var timerId = setInterval(函数, 毫秒数);   clearInterval(timerId); // 停止
00:00.0

形象理解：setInterval 就像一口"钟表"，每隔固定毫秒就"滴答"执行一次函数； 必须用 clearInterval 才能让它停下来，否则会一直跑下去（页面关了才停）。

两种定时器对比

setTimeout

延迟指定毫秒后执行一次就结束。
典型用途：广告 N 秒后自动关闭、提示框几秒后消失、延迟加载数据。

setInterval

每隔指定毫秒执行一次，无限循环。
典型用途：轮播图自动播放、秒表/倒计时、时钟、实时刷新。
