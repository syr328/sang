对象操作

访问与修改（点语法 / 方括号语法）

点语法像"按名字取快递"，方括号语法像"报单号取快递"，遇到带特殊字符的属性名只能用方括号。

遍历与检测

for...in 像"挨个念卡片上的字段"，Object.keys / values / entries 是三种不同角度的"字段清单"。

方法调用与嵌套访问

对象的方法就是"卡片上的动作"，方法里的 this 指向对象自己；嵌套对象像"卡里夹着一张小卡"。

对象与 JSON

JSON 是对象在网络上"寄快递"时的标准包装格式。
