JavaScript 程序结构

条件结构：if...else / switch · 循环结构：for / while / do...while

条件结构（根据条件选择执行路径）

if...else 多分支判断

if (syr_score >= 90) { ... }
else if (syr_score >= 60) { ... }
else { ... }

输入一个成绩，程序从上到下依次判断条件，执行第一个满足的分支。

switch 语句

switch (syr_day) {
  case 1: "星期一"; break;
  default: "输入有误";
}

switch 将表达式的值与各 case 精确匹配，break 用于跳出，default 处理其他情况。

循环结构（重复执行代码块）

for 循环

for (var syr_i = 1; syr_i <= 100; syr_i++) {
  syr_sum += syr_i;
}

初始化、循环条件、更新表达式三部分组成，适合已知次数的循环。

while 循环

while (syr_n > 0) {
  输出 syr_n; syr_n--;
}

先判断条件再执行循环体，条件不满足则一次也不执行。

do...while 循环

do { 执行一次 }
while (syr_i <= 5);

先执行一次循环体再判断条件——即使条件为假，也至少执行一次。
